8 End-to-End Flow Test
Full cycle: Pro uploads → Admin reviews → Pro sees result → Partner sees it
StepActionExpected Result
1. Pro uploads Login as Pro → floating panel → upload a missing credential Credential appears as "Pending review" in both floating panel and Credentials Status section
2. Admin approves Login as Admin → find the pending credential → Approve with all 4 fields Credential status changes to "Verified" with green badge and expiration countdown
3. Pro sees verified Login as Pro → Profile → Credentials Status Card shows green "VERIFIED" badge, metadata grid (ID, dates, org), and "View Credential" button
4. Partner sees it Login as Partner → Pros → View Profile on the caregiver Credential card shows "VERIFIED" with full metadata. Download button available. Read-only (no edit/remove)
5. Pro shares profile Login as Pro → Profile → click "Share Profile" → paste in incognito Preview page shows name, role, city, and "X of 5 credentials verified" count. CTA → partner signup
🧪 Full E2E Flow:
  1. Pro: Upload a credential → appears as Pending
  2. Admin: Approve it with metadata → status changes to Verified
  3. Pro: Refresh profile → green card with countdown timer + metadata
  4. Partner: View same caregiver → see Verified card (read-only)
  5. Admin: Reject another credential with reason → Pro sees red card with reason
  6. Pro: Re-upload the rejected credential → status goes back to Pending
